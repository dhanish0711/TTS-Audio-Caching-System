# TTS-Audio-Caching-System
An AI-powered Text-to-Speech (TTS) audio caching system designed to reduce voice generation latency to &lt;1ms. Features deterministic SHA-256 keying, gzip compression, multi-level eviction (LRU &amp; TTL), fuzzy matching, predictive warming, and a glassmorphic dashboard with real-time Web Audio API waveform visualizers and table search controllers.
